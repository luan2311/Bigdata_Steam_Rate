# Script vận hành

Đặt wrapper tạo mẫu, submit job, export snapshot hoặc benchmark tại đây khi triển khai. Script chỉ đọc tham số/cấu hình và gọi entry point/công cụ; nghiệp vụ nằm trong `src/steam_reviews/`.

Mỗi script phải ghi điều kiện chạy, đầu vào, đầu ra và exit code trong `docs/runbooks/`. Hiện chưa có script chạy pipeline.
